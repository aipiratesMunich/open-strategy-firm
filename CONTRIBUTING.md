# Contributing

Issues are the best way to help: a case where a skill gave a weak answer, a check the partner missed, a playbook you would structure differently. Please include the prompt, the agent and model you used, and what a strong answer would have looked like.

The files in `skills/*/references/` are generated from a maintained knowledge base, so edits there get overwritten. Describe the change in an issue instead and it will be carried into the next build.

All examples must use fictional companies and invented figures.
